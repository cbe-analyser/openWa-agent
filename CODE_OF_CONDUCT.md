# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, accept constructive feedback, focus on what is best for the community, and do not harass, insult or publish other people's private information. This applies in issues, pull requests, discussions and any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainers through a [private security advisory](https://github.com/cbe-analyser/openwa-agent/security/advisories/new) marked "Code of Conduct", or by contacting a maintainer directly. Reports are handled confidentially. Maintainers may warn, temporarily ban or permanently ban contributors whose behaviour violates this code, following the Contributor Covenant enforcement guidelines.
